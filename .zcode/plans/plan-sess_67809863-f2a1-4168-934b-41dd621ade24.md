# Plan: License & Device Binding — Registration UI, Fingerprinting, Expiry Enforcement

## Goals
- Provide a one-time (and re-activatable) **license registration** flow that:
  - Validates a license key.
  - Binds to the current device (fingerprint = SHA-256 hash of MAC + MachineName + OS).
  - Records device info in `DeviceInfos`.
  - Enforces expiry on every application start.
- Expose a `LicenseGuard` that `Program.cs` calls **after DB init, before login**. If invalid/missing/expired:
  - Show `LicenseRegistrationForm` modal.
  - On success → continue to login.
  - On cancel → exit cleanly.

## Decisions (defaults applied — user did not respond)
- **Behaviour on invalid**: show registration form, then continue or exit on cancel.
- **Fingerprint scope**: MAC + MachineName + OS (cross-platform, no WMI, no admin rights).
- **Layer**: Application layer (cross-platform, testable from `net8.0` test project).

### Application layer (new)
- `src/MMNextPOS.Application/Services/IDeviceFingerprintService.cs` — interface returning a `DeviceFingerprint` record (string Hash, string MacAddress, string CpuId?, string HardDiskSerial?, string MachineName, string OsVersion).
- `src/MMNextPOS.Application/Services/DeviceFingerprintService.cs` — implementation. Uses `NetworkInterface.GetAllNetworkInterfaces()` for the first non-loopback MAC, `Environment.MachineName`, `RuntimeInformation.OSDescription`. SHA-256 over the canonical string. CpuId / HardDiskSerial stay `null` (cross-platform).
- `src/MMNextPOS.Application/Services/ILicenseGuard.cs` — interface with `Task<LicenseStatus> CheckAsync(CancellationToken)`. `LicenseStatus` is a small record (`IsValid`, `Reason`, `License?`, `Device?`).
- `src/MMNextPOS.Application/Services/LicenseGuard.cs` — reads `ILicenseInfoService` + `IDeviceInfoRepository` + `IDeviceFingerprintService`. Logic:
  - If no LicenseInfo row → invalid, reason `NotRegistered`.
  - If status ≠ "Active" → invalid, reason `Status<status>`.
  - If `ExpiryDate <= UtcNow` → invalid, reason `Expired`.
  - Look up `DeviceInfo` by fingerprint. If none → invalid, reason `DeviceNotBound`.
  - If `License.MaxDevices` reached and the device row is not the one bound → invalid, reason `DeviceLimitReached`.
  - Otherwise → valid; the guard also updates `LastSeenAt` and persists.

    var licenseGuard = serviceProvider.GetRequiredService<ILicenseGuard>();
    var licenseForm = serviceProvider.GetRequiredService<LicenseRegistrationForm>();

    if (!status.IsValid)
    {
        // show form; on OK, re-check; on Cancel, return
        licenseForm.Prepopulate(status);
        if (licenseForm.ShowDialog() != DialogResult.OK) return;

    }

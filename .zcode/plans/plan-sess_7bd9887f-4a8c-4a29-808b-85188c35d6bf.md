# Implementation Plan: LoginForm with Async Login via IUserService and Role Resolution

## Overview
Create a secure login form using DevExpress WinForms with async authentication, BCrypt password hashing, and role-based navigation filtering.

## Changes Required

### 1. Add BCrypt NuGet Package
- **Project**: `MMNextPOS.Application` 
- **Package**: `BCrypt.Net-Next` (modern, maintained fork)

### 2. Extend `IUserService` Interface (`src/MMNextPOS.Application/Services/IUserService.cs`)
Add authentication method:
```csharp
Task<User?> AuthenticateAsync(string username, string password, CancellationToken cancellationToken = default);
Task<IReadOnlyList<Role>> GetUserRolesAsync(int userId, CancellationToken cancellationToken = default);
```

### 3. Implement Authentication in `UserService` (`src/MMNextPOS.Application/Services/UserService.cs`)
- Inject `IUserRoleRepository` and `IRoleRepository`
- Implement `AuthenticateAsync`: find user by username, verify BCrypt hash, update `LastLoginAt`
- Implement `GetUserRolesAsync`: join UserRole + Role tables

### 4. Create `LoginForm` (`src/MMNextPOS.WinForms/LoginForm.cs`)
- Inherit from `AsyncFormBase` (consistent async pattern)
- DevExpress-styled UI: username/password fields, "Remember me" checkbox, Login button
- Use `RunAsync` for async login call
- Show splash/progress during authentication
- Return `DialogResult.OK` with authenticated `User` and `IReadOnlyList<Role>` on success

### 5. Create `UserSession` Service (`src/MMNextPOS.Application/Services/IUserSession.cs` + `UserSession.cs`)
- Scoped service to hold current `User` + `Roles` throughout app lifetime
- Injected into `MainForm` for role-based UI filtering

### 6. Modify `Program.cs` (`src/MMNextPOS.WinForms/Program.cs`)
- Register `LoginForm` and `IUserSession` in DI
- Show `LoginForm` modally first
- On success: populate `UserSession`, launch `MainForm`
- On cancel/fail: exit application

### 7. Modify `MainForm` (`src/MMNextPOS.WinForms/MainForm.cs`)
- Accept `IUserSession` in constructor
- Store current `User` + `Roles`
- Filter navigation pages based on user roles (using `IMainNavigationService`)
- Show username/role in UI (status bar or header)

### 8. Register New Services in `DependencyInjection.cs`
- `IUserSession` → `UserSession` (Scoped)
- Ensure `IUserRoleRepository` and `IRoleRepository` are available (already registered)

## Security Considerations
- Passwords verified via BCrypt (never stored/plain text)
- Failed login attempts: generic error message (no user enumeration)
- `LastLoginAt` updated on successful auth
- `IsActive` flag checked before allowing login

## UI/UX Details
- DevExpress `XtraForm` with modern styling
- Username field: `TextEdit`, Password field: `TextEdit` with `PasswordChar = '●'`
- Enter key triggers login; Escape cancels
- Loading indicator via `SplashScreenManager` during auth

## Testing
- Add `UserServiceTests.AuthenticateAsync_*` tests in `tests/MMNextPOS.Application.Tests/`
- Test: valid credentials, invalid password, inactive user, non-existent user
